## 📖 معرفی پروژه

**Vid Studio** یک نرم‌افزار دسکتاپ برای استخراج، مشاهده، ویرایش و بازسازی فایل‌های ترجمه بازی‌های ساخته‌شده با Unreal Engine 4 و Unreal Engine 5 است.

این برنامه با استفاده از Python و PySide6 توسعه داده شده و با فراهم‌کردن ابزارهای مختلف، فرایند بومی‌سازی بازی‌ها را ساده‌تر می‌کند.

Vid Studio امکان کار مستقیم با فایل‌های PAK، شناسایی و استخراج فایل‌های LOCRES، ویرایش رشته‌های متنی، مدیریت تغییرات و ساخت بسته‌های ترجمه جدید را در یک محیط یکپارچه فراهم می‌کند.

## ✨ امکانات و قابلیت‌ها

### 📦 مدیریت فایل‌های PAK
- باز کردن فایل‌های PAK با قابلیت Drag & Drop
- پشتیبانی از خواندن ساختار PAK نسخه‌های 1 تا 11
- شناسایی خودکار فایل‌های Localization
- پشتیبانی از کلیدهای AES برای فایل‌های رمزگذاری‌شده
- استخراج فایل‌های موردنیاز از داخل PAK
- ساخت PAK جدید شامل فایل‌های تغییرکرده

### 📝 ویرایش و مدیریت ترجمه‌ها
- پشتیبانی از فایل‌های LOCRES نسخه‌های Legacy، V0، V1، V2 و V3
- نمایش و ویرایش مستقیم رشته‌های ترجمه
- جست‌وجوی پیشرفته در متن‌ها
- فیلتر رشته‌های تغییرکرده و ترجمه‌نشده
- پشتیبانی از Undo / Redo
- ذخیره تغییرات در پایگاه داده SQLite به‌صورت پروژه‌محور
- بازسازی فایل LOCRES با ساختار باینری سازگار
- پشتیبانی از Virtual Pagination برای مدیریت بیش از 100 هزار رشته
- قابلیت تغییر اندازه ستون‌های جدول مانند نرم‌افزار Excel

### ⚙️ مشاهده فایل‌های جانبی
- مشاهده و استخراج فایل‌های INI
- حفظ Encoding و ساختار فایل‌های INI هنگام پردازش
- نمایش ساختاریافته فایل‌های LOCMETA
- نمایش اطلاعات Metadata و Hex Dump

### 🎨 رابط کاربری
- رابط کاربری مدرن مبتنی بر PySide6
- تم تاریک (Dark Theme)
- صفحه خوش‌آمدگویی دوزبانه
- ذخیره تنظیمات رابط کاربری با QSettings
- پنجره About دوزبانه (فارسی / انگلیسی)

## 🎮 راهنمای استفاده

### ۱. باز کردن فایل PAK

فایل PAK بازی را با استفاده از قابلیت Drag & Drop وارد برنامه کنید یا از گزینه `Open PAK` استفاده کنید.

برنامه ساختار فایل را پردازش کرده و فایل‌های Localization موجود را شناسایی می‌کند.

### ۲. مشاهده و ویرایش ترجمه‌ها

پس از بارگذاری فایل LOCRES، رشته‌های متنی در جدول ویرایش نمایش داده می‌شوند.

متن ترجمه را می‌توانید مستقیماً از ستون `Translation` تغییر دهید.

همچنین امکان جست‌وجو، فیلتر و مدیریت رشته‌های ترجمه وجود دارد.

### ۳. ذخیره تغییرات

با انتخاب گزینه `Save Changes`، تغییرات در پایگاه داده پروژه ذخیره و برای ساخت خروجی آماده می‌شوند.

### ۴. ساخت فایل PAK جدید

از گزینه `Build PAK` برای ساخت بسته ترجمه استفاده کنید.

برنامه فایل‌های تغییرکرده را پردازش کرده و در قالب یک PAK جدید خروجی می‌گیرد.

## 🔐 پشتیبانی از فایل‌های رمزگذاری‌شده

Vid Studio از فایل‌های PAK رمزگذاری‌شده با AES پشتیبانی می‌کند.

برای بارگذاری این فایل‌ها:

1. گزینه `Set AES Key` را انتخاب کنید.
2. کلید رمزگذاری بازی را وارد کنید.
3. کلید می‌تواند در قالب Base64 یا Hex ارائه شود.
4. پس از ثبت کلید، عملیات پردازش فایل را انجام دهید.

بدون کلید معتبر، محتوای فایل‌های رمزگذاری‌شده قابل استخراج نیست.

## 📦 ساخت نسخه مستقل ویندوز (EXE)

برای ساخت نسخه مستقل برنامه که بدون نیاز به نصب Python روی سیستم مقصد اجرا شود، از PyInstaller استفاده کنید.

### نصب PyInstaller

```bash
pip install pyinstaller
```

### ساخت خروجی

```bash
pyinstaller --noconfirm --clean VidStudio.spec
```

پس از پایان فرایند، خروجی در مسیر زیر قرار می‌گیرد:

```text
dist/
└── VidStudio/
    ├── VidStudio.exe
    ├── oo2core_9_win64.dll
    └── _internal/
        ├── Python Runtime
        ├── PySide6
        ├── Database
        ├── Assets
        └── Dependencies
```

### بررسی سلامت نسخه ساخته‌شده

برای اجرای مجموعه تست‌های اعتبارسنجی داخلی نسخه خروجی:

```powershell
& ".\dist\VidStudio\VidStudio.exe" --verify-suite
```
